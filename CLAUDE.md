# AlertShield

CI/CD pipeline intelligence & cost optimizer. See `OVERVIEW.md` for the product brief.

## Toolchain

Use **pnpm**, never npm. `pnpm install`, `pnpm <script>`, `pnpm dlx` (not `npx`).

## Agent skills

### Issue tracker

Issues live as GitHub issues, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, with label strings equal to their names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
